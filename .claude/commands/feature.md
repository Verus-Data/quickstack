# Feature

Read AGENTS.md and relevant rules. Clarify the feature and write a focused RFC in plans/ (`rfc-topic.md` at the plans level, added to the plans/README.md table with a one-line status, per the conventions there) explaining behavior, boundaries, failure modes, and acceptance tests. Obtain one adversarial design review from the architect agent, then one from `ce:devils-advocate` on the RFC; apply their findings without sending the RFC back for a second pass. Implement in an isolated worktree with independent subtasks delegated only when useful; each delegated brief carries the constraints in rules/agent-ops.md and asks for its deliverable in a file. Run the project check command and exercise the feature through the actual interface. Use project-documented development servers and test harnesses; stop only processes you started. Request `ce:code-reviewer` once, address its findings, and create a PR using the repository template. Merge only when authorized and checks pass. Preserve deliverables and clean up the task worktree after handoff.
