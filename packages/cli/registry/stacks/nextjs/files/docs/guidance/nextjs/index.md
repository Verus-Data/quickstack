# Next.js guidance

Read these references before changing the corresponding code. They apply to every agent; Claude rules link here.

The framework's own docs for the installed release are in `node_modules/next/dist/docs/` (getting started, guides, API reference, CLI). Check them before using a Next API or config option from memory; conventions change between majors.

- [app-router](app-router.md): pages, server and client components, Server Actions, route handlers, caching and errors.
- [testing](testing.md): what Vitest covers, what Playwright covers, and how to run each.
- [typescript](typescript.md): compiler settings and type-safety traps.
- [verification](verification.md): checks before calling work done.
