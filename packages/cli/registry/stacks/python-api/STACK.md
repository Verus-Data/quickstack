# FastAPI service (Python API)

A FastAPI JSON API at the repo root, run by Uvicorn and managed by uv. There is no frontend and no Node toolchain. The root `Makefile` is the entry point for everything. The committed `openapi.json` is the contract callers code against, and verify fails when it drifts from the app.

## Layout

```
Makefile, .env.example, README.md
pyproject.toml, uv.lock, .python-version
openapi.json           generated by make openapi, committed
app/main.py            create_app() factory + module-level app
app/config.py          Settings (pydantic-settings) + cached get_settings()
app/lifespan.py        long-lived resources on app.state
app/errors.py          AppError hierarchy + handlers
app/logging.py         structlog setup
app/middleware.py      request-id middleware
app/routers.py         register_routers(app), the one place routers mount
app/api/               one module per area exporting `router` (health.py, items.py)
app/schemas/           pydantic wire models
app/services/          plain business logic and stores (no FastAPI imports)
scripts/dump_openapi.py
tests/
```

## Setup

1. **Project.** Run `uv init` non-interactively in a temporary directory for an unpackaged application: no `src/` layout, no build backend, no stub `main.py` or README (check `uv init --help` for the bare form). Move its `pyproject.toml` to the root, set the project name to the project slug, and leave the shipped root files as they are. At the root, pin the Python version from Decisions (`uv python pin` writes `.python-version`) and make `requires-python` match it (uv may default to an older interpreter it finds). `uv add` the runtime deps (Uvicorn with its standard extra), `uv add --dev` the dev deps.
2. **App** per Conventions: `GET /health` returns `{"status": "ok"}` with no dependencies.
3. **Example resource.** `items` under `/v1/items`: `POST` creates one (name required, 1 to 100 characters; 201 with the created item), `GET` lists them. The store lives in `app/services/`, is created in the lifespan and reached through a `get_item_store` dependency. When the store raises its unavailable error, the route returns 503 with the envelope.
4. **Tooling** per Tool configuration in `pyproject.toml`. Add `scripts/dump_openapi.py`, run as `uv run python -m scripts.dump_openapi <path>` so it can import `app`, then `make openapi`.
5. **Tests** per Testing; get `make test` green.
6. Fill the README's `stacks:fill` marker, then run `stacks verify` until it passes.

## Conventions

- **Factory.** `create_app(settings: Settings | None = None)` configures logging, lifespan, middleware, exception handlers and `register_routers(app)`. `main.py` ends with `app = create_app()`. Importing `app.main` has no side effects (no network, database or file writes), so `dump_openapi.py` and tests can import it.
- **Config.** One `Settings(BaseSettings)` with working dev defaults, reading env and `.env`, `SecretStr` for secrets, `__` nested delimiter. Set it to ignore extra keys: `.env` also holds Make and Compose variables, and pydantic-settings rejects undeclared `.env` keys by default. `get_settings()` is `lru_cache`d and injected with `Depends` so tests override it.
- **Lifespan** owns every long-lived resource on `app.state` and closes it on shutdown; no module-level singletons that connect at import.
- **Routers.** Each `api/<area>.py` exports `router = APIRouter(prefix=..., tags=[...])`, mounted only in `routers.py`. Resources under `/v1`; `/health` at the root. Dependencies use `Annotated[T, Depends(fn)]`. Routes stay thin: parse, call a service, return a model.
- **Errors.** Raise `AppError` subclasses rather than `HTTPException`. `AppError` (`code` UPPER_SNAKE, `message`, `status_code`, `details`) with `NotFoundError`, `ConflictError`, `ValidationFailed`, `Unauthorized`, `Forbidden` and `ServiceUnavailable` (503, for a dependency that is down). Handlers render everything, including request validation errors and `HTTPException`, as `{"error": {"code", "message", "details", "requestId"}}`. Validation errors are 422 `VALIDATION_FAILED` with the field errors in `details`. The catch-all logs the exception and returns 500 `INTERNAL_ERROR` (exception detail only in development). Declare the envelope model in `responses=` so the spec documents it.
- **Wire models.** A shared `ApiModel` pydantic base with camelCase aliases (serialize by alias, accept both on input); Python code stays snake_case.
- **Logging.** structlog, JSON lines to stdout outside development, console rendering in development. Uvicorn's access log is off or routed through structlog, so one request writes one line. The middleware accepts `X-Request-ID` or generates one, binds it to structlog's context variables for the request, echoes it on the response, and clears it afterwards. Every request logs one line with method, path, status, duration and request id.
- **OpenAPI is the contract.** Every route has a `response_model` and a summary; `generate_unique_id_function` yields `<tag>_<function_name>` so operation ids don't churn. `dump_openapi.py` writes sorted keys, two-space indentation and a trailing newline.

## Tool configuration

- **ruff**: target the project's Python, line length 100. Select E, W, F, I, B, C4, UP, ARG, SIM, TC, PTH, ERA, PL, RUF, ASYNC, S, T20; ignore E501, PLR0913; tests may ignore S101, PLR2004, ARG. `app` is first-party. `ruff format` formats.
- **mypy**: strict, `warn_unused_ignores`, `warn_redundant_casts`, pydantic plugin; relax `disallow_untyped_defs` for `tests.*`; per-module `ignore_missing_imports` only for untyped libraries.
- **pytest**: asyncio auto mode, function-scoped loops, `testpaths = ["tests"]`, `--strict-markers --strict-config -ra`, markers `slow` and `integration`, `filterwarnings = ["error"]` with commented targeted ignores.
- **coverage**: source `app`, branch, parallel, `fail_under = 80`, exclude `if TYPE_CHECKING:`.

## Testing

- Shared fixtures in `tests/conftest.py`: build `create_app(test_settings)`, enter its lifespan with asgi-lifespan's manager, and call it through `httpx.AsyncClient` with `ASGITransport`. Every test goes through real routing, middleware and handlers.
- Cover: health; create then list; a 422 for a missing and an over-long name with the envelope and field details; a 503 by overriding `get_item_store` (`app.dependency_overrides`) with a store that raises; an unknown path's 404 in the envelope; the request id echoed when sent and generated when absent; and the 500 envelope from a route that raises, mounted only in the test app.
- Assert the log line: capture stdout with JSON rendering on and parse it, or use structlog's testing capture; check that it carries the request id.
- Test services directly. Stub outbound HTTP at the transport (`httpx.MockTransport`), never your own code.
- `make test` stays fast; `make coverage` enforces the floor.

## Commands

The shipped `Makefile` (`make help`) has install, lint, format, typecheck, test, coverage, dev, start, openapi, check-openapi and clean. `check-openapi` dumps the spec to a temp file and compares it with `openapi.json` as parsed JSON, so formatting doesn't matter; run `make openapi` after any route or model change and commit the spec with it. Mirror the targets and a single-test command (`uv run pytest tests/test_items.py`) in AGENTS.md. The shipped `.claude/settings.json` already allows the non-destructive targets.

**CI.** One `ci-ok` job: uv's setup action (cache on, `.python-version`), then `make install lint typecheck coverage check-openapi` with `CI` set. Use `test` instead of `coverage` if the coverage decision is no.

## Gotchas

- If ruff's TC rules are on, they move annotation-only imports under `if TYPE_CHECKING:`, but FastAPI and pydantic evaluate annotations at runtime, so a moved import breaks startup. Set ruff's runtime-evaluated base classes (`pydantic.BaseModel`, `pydantic_settings.BaseSettings`) and ignore TC in `app/api/` and `tests/`: ruff matches decorators by qualified name, while `@router.get` is an attribute of a router instance, so the decorator setting does not apply.
- `httpx.ASGITransport` doesn't run the lifespan; without the lifespan manager, `app.state` is empty and every route that needs a store fails.
- Starlette re-raises an unhandled exception after the 500 response is sent, and `ASGITransport` raises it into the test by default. The 500 test builds its client with app exceptions not raised (check the installed httpx for the option).
- `filterwarnings = error` turns upstream deprecations into failures; add targeted ignores, don't drop the rule.
- ruff renames rule prefixes across releases; switch to the new code when it warns.
- `make start` binds `127.0.0.1`. A container or remote host needs `make start API_HOST=0.0.0.0` (or uvicorn's own `--host`); keep the Makefile default local.
